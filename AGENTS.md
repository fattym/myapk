# AGENTS.md

Flutter project for MyBidhaa - School Books & Supplies Kenya.

## Commands

- Install dependencies: `flutter pub get`
- Run linter: `flutter analyze`
- Run the app: `flutter run`
- Build APK: `flutter build apk`
- Run tests: `flutter test`

## Project Structure

- `lib/models/` - Data models
- `lib/providers/` - State management (Provider pattern)
- `lib/screens/` - App screens
- `lib/widgets/` - Reusable UI components
- `lib/widgets/modals/` - Interactive dialogs and modals
- `lib/data/` - Sample/mock data
- `lib/theme/` - App theme and color constants
- `lib/utils/` - Utility functions
